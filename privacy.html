Privacy Policy

Last updated: October 24, 2026

This site is a demonstration storefront. It uses browser storage for demo catalog settings, preferences, and saved records. Information you enter into the support request form is sent to this server and held temporarily in server memory for review; it is lost when the server restarts. Do not submit payment details, passwords, or other sensitive information.

Information and purposes

  • Support requests include your name, contact details, request type, and message so the store can respond.
  • Catalog changes and wishlist or comparison preferences may be kept in this browser using local storage.
  • Basic technical request data may be processed by the web server to deliver and protect the site.
  • Optional Google Analytics is loaded only after you choose “Allow analytics.” It is not configured until the site owner supplies a measurement ID.
  • Campaign source tags (UTM values) may be included with a support request to understand which campaign led to it.

Choices and retention

You can choose essential storage only in the privacy banner. You can clear this site’s browser storage through your browser settings. Server-side support requests are temporary and are not backed by durable storage in this demo.

Contact

Use the support request form for questions about this demonstration. No legal entity, jurisdiction, or dedicated privacy contact has been supplied for this sample site.
